# assets/

Coloque aqui as **imagens** do jogo (uso pessoal).

Sugestão de organização (crie as subpastas conforme for adicionando):

```
assets/
├── clubes/        escudos dos clubes        ex: clubes/rio-atletico.png
├── ligas/         logos das ligas           ex: ligas/liga-brasil.png
├── selecoes/      bandeiras/escudos          ex: selecoes/brasil.png
├── jogadores/     fotos de jogadores         ex: jogadores/123.png
└── ui/            ícones e arte de interface
```

Formatos recomendados: **PNG** (com fundo transparente) ou **WEBP**.
Depois a gente conecta essas imagens aos dados em `data/`.
